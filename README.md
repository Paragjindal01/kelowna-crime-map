# Kelowna Crime Map 

Kelowna Crime Map is a web application that displays crime report locations on an interactive map.  
The project focuses on visualizing location-based data in a clear and user-friendly way using modern web technologies.

The current version uses generated data for development purposes and is structured to support future integration with real datasets.

---

## Features

- Interactive map with zoom and pan
- Clustered markers for better readability
- Display of crime type and occurrence date
- REST API endpoint for fetching reports
- Clean and scalable project structure

---

## Tech Stack

### Frontend
- Next.js (App Router)
- React
- TypeScript
- Leaflet / React-Leaflet

### Backend
- Next.js API Routes
- Prisma ORM
- Generated development data
